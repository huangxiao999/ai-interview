## 2. 实际范围与归属

M-06负责公共知识构建、批次、尝试、候选及完整向量接收。新增V8：`knowledge_index_build/batch/attempt/candidate/vector/request`。不修改V1～V7，未新增依赖或通用调度平台。

固定知识根/批准版本/摘要、分块修订、片段ID/顺序/原文偏移及摘要、供应商/地区/业务空间/端点/模型/维度/document类型。配置快照不含密钥。相同版本+配置+分块策略唯一，跨维护者和请求UUID复用原构建；同一请求不同输入/种类冲突。索引操作与既有提交/审核在同账号锁下防止请求UUID交叉复用。

分块v1按段落优先，长段最多1000 Unicode码点，无重叠，每请求最多10片段；偏移是Java UTF-16索引，拼接仍为固定原文。该保护不是token计量、真实检索定标或供应商最大容量证明。构建中间向量存PG的1024维数值数组，完整批次原子接收；P3-DT-03再建立pgvector检索表示、不可变集合与发布，不伪称本轮已有向量搜索。

全部新增正文、候选和向量均为已审核公共知识，无用户简历/JD、私有检索、文件或私有候选，因此不扩展M-02私有清理类型；后续实际新增私有对象必须同任务接入删除屏障及清理汇总。

## 3. 事务、期限与恢复

- 写请求执行 `requireCurrent`，固定账号→知识根顺序；后台通过 `lockCurrentAccount`核当前维护权限，再取同一知识根锁并重查批准版本/摘要。重置旧会话不自动取消已受理后台工作，撤销维护角色则不得接收新结果。
- 受理事实和固定批次同事务保存，用户请求与数据库派发意图均有独立幂等身份。短事务使用同一数据源/TransactionTemplate，工程事务超时5秒；所有HTTP在事务外。
- 每批60秒，从领取并记录尝试起算；排队20秒独立，后续批次可执行时登记其排队起点。外调前持久意图计次，最多3次，无自动外调。提交意图未知时执行方法抛出，不会按内存意图直接发送。
- 单活动应用仅一个后台外调句柄，独立执行线程不阻塞既有清理调度；忙碌时不追加线程或排队句柄。HTTP绝对截止主动关闭传输，接收仍按数据库时间和代次核实，不能据本地取消推断远端未执行。
- 超时/重启未持久候选标 `EXTERNAL_UNKNOWN`，失效原代次。所有已派发批次再次外调都逐次确认可能重复收费，包含已收到但不合规的响应；原候选接收和未派发排队恢复不要求费用确认。未知用量留空并标未知；本轮无真实价格估计或账单，不填0元。
- 截止前完整候选已持久，后续接收失败保留候选；状态暂停，人工恢复或重启继续同候选，不受原外调期限限制，不新增调用。接受向量、批次完成、构建成功同事务；部分写失败全部回滚。
- 同绑定失败耗尽后不提供强制重建入口。构建SUCCEEDED只表示全批次接收，不切发布指针，不表示召回、引用支持或AI质量通过。

## 5. API与页面

在 `/api/maintenance/knowledge` 下：

| 方法/路径 | 契约 |
| --- | --- |
| POST `/documents/{root}/versions/{version}/index-builds` | 固定digest，账号/请求头/CSRF，受理或返回同绑定构建 |
| GET 同路径 | 固定版本的公共构建状态列表，仅维护者 |
| GET `/index-builds/{id}` | 原构建、批次、尝试代次及剩余预算，无原始候选/凭据 |
| POST `/index-builds/{id}/resume` | 原attemptId和本次acceptPossibleDuplicateCharge；同请求复发不重复恢复 |
| GET `/index-operations/{operation}` | 当前维护者自己的原创建/恢复请求 |

成功200、no-store。未配置服务503 `INDEX_SERVICE_UNAVAILABLE`明确未派发；数据库/提交不可核实503 `RESULT_UNKNOWN`；外部未知人工确认缺失409 `INDEX_RETRY_CONFIRMATION_REQUIRED`；沿用401/403、INVALID_INPUT、ACCOUNT_CHANGED、OPERATION_CONFLICT、KNOWLEDGE_STATE_CONFLICT及RESOURCE_UNAVAILABLE。

独立 `/app/knowledge-index` 页经统一API/Pinia操作：原请求输入固定、原操作查询、构建状态/预算/逐次费用确认。只有即将业务POST时才保存账号绑定操作ID，预检失败不留回执；刷新只查询不恢复付费确认或正文；身份核实/切换清内存并拒绝旧响应，匿名/异账号清最小回执。
