## 3. 边界及后续

- 旧 Session **逻辑撤销**由新账号代次立即生效；物理清理是尽力执行。重置后已经发出的响应和离线屏幕无法撤回。清理遇到损坏的 Session 属性或数据库故障时，旧行可存留至过期，但后续受保护请求仍须重查版本。
- 维护命令在事务提交后才展示新密码；若进程恰在提交后、展示前崩溃，操作者应先核实账号状态，再通过受控重置产生下一份新密码，不能猜测上次是否提交。当前未建设跨进程可恢复的一次性密码交付机制。
- 本机所有者/ACL 是当前 Windows 检出的维护边界，不代表生产运维授权。生产部署前需要单独核实受控操作身份及凭证交付渠道。
- DT-05 产品登录页面、DT-06 前端响应丢失和多窗口恢复、真实私有对象归属验证，以及 DT-02 仍待补的独立证据均未因本任务自动完成。
