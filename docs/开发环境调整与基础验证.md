## 5. 可重复命令

```powershell
# 目录：项目根；先在本机准备 JDK21，现有 .env 不覆盖
& './scripts/Use-LocalTools.ps1'
java -version
javac -version
docker compose config --quiet
docker compose pull postgres
docker compose up -d --wait postgres

# 目录：项目根；只读 SQL，使用容器自己的已配置账号，不打印密码
Get-Content -LiteralPath infra/postgres/verify.sql -Raw | docker compose exec -T postgres sh -c 'exec psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB" -A -t'
docker image inspect pgvector/pgvector:pg16 --format '{{json .RepoDigests}}'

# 目录：backend；先停止使用同一 JAR 的本次应用进程再构建
Set-Location backend
./mvnw.cmd --version
./mvnw.cmd '-Dmaven.repo.local=../.cache/maven-repository' -B -ntp verify
$env:SERVER_PORT='18080'
java -jar target/interview-coach-backend-0.0.1-SNAPSHOT.jar --spring.profiles.active=local
```

另一个 PowerShell 终端执行：

```powershell
# 目录：任意；只检查上述已启动的 local 应用
Invoke-RestMethod -Uri 'http://127.0.0.1:18080/actuator/health' -NoProxy
```

命令中的18080是本次明确选取的验证端口。先检查可用性，不停止其他进程；默认工程端口仍8080。停止本次应用用其终端 Ctrl+C。不要使用 `down -v`，不挂载已有 PG18 数据目录到 PG16。
