## 3. 历史实现契约摘要

以下摘要来自上述历史提交，不能替代当前代码核查或正式业务确认来源。

| 能力 | 历史交付与保护 |
| --- | --- |
| 发布源 | 从生产接口取得片段 ID、原文、偏移、摘要及来源，再由维护者填写适用条件和 claim/quote；不靠直接查库拼正常发布输入 |
| 原子发布 | 固定操作身份、预期当前集合、构建/片段清单和配置；核全部批次及片段完整性。集合、条目、回执和指针共同提交；账号→稳定排序知识根→指针锁，竞争失败返回冲突 |
| 原结果查询 | 相同操作和固定输入返回原集合；提交确认丢失先查原回执，404 不单独证明从未受理，不换操作 ID 猜结果 |
| 工程检索 | 固定集合/configDigest，精确筛选技术、版本、场景及 claimKey 后用 pgvector 精确 cosine；工程参数 TopK=5、阈值0.7、原文总量5000 Unicode码点，尚未完成真实质量/token预算定标 |
| 冲突与引用 | 同条件 claimValue 冲突在阈值和 TopK 裁剪前登记；quote 连续摘录、来源锚点及人工说明只提供可核查结构，不证明语义蕴含 |
| 版本停用 | 追加停用事实，保留原审核及已接受批次；在派发、恢复、接收、发布和探测中重查。失效代次防迟到候选复活，合法迟到用量仅补原尝试审计 |
| 事务与迁移 | Spring JDBC/TransactionTemplate 短事务，外调在事务外。追加 V9，不改 V1～V8；Flyway 同库专用迁移连接与业务 app schema 边界分别核实 |

历史维护前缀为 `/api/maintenance/knowledge`：

| 接口 | 用途 |
| --- | --- |
| `GET /index-builds/{id}/publication-source` | 读取真实发布源片段 |
| `POST /collections` | 按固定输入和预期指针发布 |
| `GET /collections/current`、`GET /collections/{id}` | 查询当前指针或固定集合 |
| `POST /collections/{id}/probe` | 用公共/合成1024维向量探测，不调用真实embedding |
| `POST/GET /documents/{root}/versions/{version}/stop` | 登记/查询原版本停用事实 |
| `GET /collection-operations/{operation}` | 核实原维护操作回执 |

接口使用维护角色、Session/CSRF 和预期账号身份；写入固定操作 ID，响应禁止缓存。错误区分输入、身份/权限、冲突、服务故障及结果未知。集合保持 `runtimeReady=false`，工程证据不能直接用于真实评分。
