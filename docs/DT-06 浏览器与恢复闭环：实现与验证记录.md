## 2. 实际场景与可观察结果

| 场景 | 故障与顺序 | 结果 |
| --- | --- | --- |
| 直接访问与登录 | 匿名直接进入 `/app`，以合成 A 登录 | 先查 `me` 并转登录；成功后显示 A，`SESSION` 不可由页面脚本读取。 |
| 退出回包丢失 | 退出 POST 已到后端；浏览器丢弃可读响应 | 仅发一次退出 POST，随后查 `me` 得 401，显示登录页；不重发退出。 |
| 登录结果未知 | 登录 POST 已成功并设置 Cookie；浏览器丢失响应，首次 `me` 查询也失败 | 显示身份未知、隐藏登录表单，不重新提交 POST；用户点击“重新核实”后由 `me` 确认 A 并进入工作区。 |
| 双窗口与迟到响应 | W1 的 A 身份响应在浏览器内暂扣；W2 退出 A 并登录 B；W1 收到同步通知后查得 B，再放出旧 A 响应 | W1 不再显示 A，保持 B；浏览器直接查 `me` 的账号 ID 是 B。广播本身不携带账号或私有正文。 |
| 数据库暂不可用 | 在隔离库短暂改名 `identity_account`；W1 重新核实 | 后端不能核实身份时页面显示未知并遮蔽 B；表恢复后点击核实重新显示 B。 |
| 过期与重登 | 将隔离库 Session 的最后访问时间和到期时间置为过期；访问 `me` 并重新获焦 | 后端返回 401，页面显示登录已失效且无旧 B；重新登录后显示服务端当前 B。此夹具验证到期后行为，1800 秒边界已有 DT-03 证据，不声称实际等待 30 分钟。 |
| 返回路径 | 未登录原入口 `/app`；另以协议相对、外站、脚本与路径绕行值作为 `redirect` | 仅回 `/app`，Chrome 保持本站 origin；不存在的私有资源路径不被提前承诺。 |
