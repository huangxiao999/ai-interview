## 2. 本轮设计与实现

### 2.1 发布与固定身份

新增[集合服务](../backend/src/main/java/dev/interviewcoach/knowledge/KnowledgeCollectionService.java)、[仓储](../backend/src/main/java/dev/interviewcoach/knowledge/KnowledgeCollectionRepository.java)、[策略与契约](../backend/src/main/java/dev/interviewcoach/knowledge/KnowledgeCollectionPolicy.java)、[HTTP入口](../backend/src/main/java/dev/interviewcoach/knowledge/KnowledgeCollectionApi.java)及[V9](../backend/src/main/resources/db/migration/V9__publish_knowledge_collections.sql)。复用Spring JDBC/TransactionTemplate，短事务5秒。

发布固定账号、操作身份、预期当前集合、构建/片段清单、人工适用条件与claim标注。检查全部批次ACCEPTED、源原文完整覆盖、分块序号/批次归属/偏移/摘要一致，配置同身份且分块政策一致。jsonb会格式化键/空白，用原Chunk类型重建原序列核输入摘要；不hash数据库格式化文本猜原摘要。quote必须是对应原片段的连续摘录；人工claimValue不构成独立语义证明。

集合头、全体pgvector条目、原操作回执与唯一指针原子提交。账号→UUID排序知识根→指针锁，预期指针比较失败409；同操作重放返回原集合，不能改指针到最新或再次发布。跨提交/审核/构建/集合/停用的操作身份冲突拒绝。旧版本/索引/集合不重写。

### 2.2 工程探测

只接受维护者给定的公共/合成向量，不调用embedding；输入固定集合ID/configDigest、technology/technologyVersion/scenario/claimKey，条件缺失返回不足。不接收用户简历/JD或私有资源ID，查询向量/文本不落库。

原schema基线为app，vector扩展在public；运行SQL明确`public.vector`及`OPERATOR(public.<=>)`，不靠扩大search_path或更改全局schema来隐藏问题。先筛审核/停用及精确条件，再做精确cosine。工程政策TopK5/阈值0.7/原文总5000码点；token预算和真实召回未定标，不把码点当token，不构造模型提示词。SQL参数化，无HNSW或外部向量服务。

同条件claimKey不同claimValue在阈值/TopK前报CONFLICT_UNRESOLVED，返回具体冲突片段/版本/来源身份。候选有实际原文位置/摘要/审核时间/来源锚点、quote及人工核对说明，EVIDENCE_AVAILABLE只代表候选；`runtimeReady=false`，不能拿来开放真实评分。链接存在、quote连续或向量相近不自动代表语义支持。实际20例引用/适用性评审仍开放。

### 2.3 停用屏障

停用是版本级追加事实，保留原审核。账号→知识根锁内共同登记停用并失效尚未终结的构建/批次、增加失效代次；已ACCEPTED批次及终结构建保持原审计事实。findApproved、原构建新受理/恢复、后台派发/接收、集合发布及探测共同核该资格。已存候选仅供审计，停用后不能恢复成可用结果；迟到响应只能补原attempt有效回执，不能新增候选/向量。原批准、候选、旧集合及历史证据不删除，不追溯改分；修复走新版本重新审核。

停用不保证撤销停用前已受理的物理请求或供应商执行/费用；本轮无真实调用。后台密码重置/账号角色规则及原预算60秒/排队20秒/每批3次/无自动外调不变。

## 3. API与可核实结果

共同前缀`/api/maintenance/knowledge`，沿用维护角色、Session/CSRF。发布/停用带`X-Expected-Account-Id`、`X-Operation-Id`；探测带预期账号头及CSRF。响应no-store，400非法输入、401身份过期、403权限/CSRF、404不可访问、409身份/状态冲突、503/RESULT_UNKNOWN分别表达；503后核原操作，不换身份猜结果。

原操作GET返回404仅代表这次未查得，不足以清除历史未知身份；后续仍用同一身份/固定输入核实或重放。发布是短事务同步操作，没有新增异步排队状态机。

| 方法/路径 | 输入/结果 |
| --- | --- |
| GET /index-builds/{id}/publication-source | 返回真实片段ID/原文/位置/摘要和来源，维护者据此填人工条件/claim，无需直接查数据库；eligible仅是初步资格，不替代发布重查 |
| POST /collections | expectedCurrentCollectionId（首发null）及builds；返回原collectionId/configDigest/政策/清单摘要/条目数/runtimeReady=false |
| GET /collections/current；GET /collections/{id} | 当前指针或固定集合元数据；新发布不改变旧集合 |
| POST /collections/{id}/probe | configDigest、conditions、claimKey、1024维vector；返回证据/不足/冲突及候选/冲突身份 |
| POST /documents/{root}/versions/{version}/stop | digest、reason；返回固定版本、停用者、原因和时间 |
| GET /documents/{root}/versions/{version}/stop | 读取原停用事实，原审核状态仍可为APPROVED |
| GET /collection-operations/{operation} | 仅原维护账号可读kind/resourceId/inputDigest；确认丢失后先查该回执再读资源 |

发布单个selection字段：buildId、conditions（technology、technologyVersion、scenario）、claims。每个claim包含chunkId、claimKey、claimValue、quote、verificationNote；必须覆盖该构建所有实际片段，不靠维护者传来的假片段ID或另一片段正文冒充来源。最多20构建/500片段。数值及身份从原生产构建查询，不在示例填造真实UUID。
