## 3. 业务事实与未覆盖项

- 保存正文按统一换行、去首尾空白后的 Unicode 码点计数，不截断。重复创建使用原操作 ID 返回原版本；相同 ID、不同正文返回冲突。固定版本 ID 不随重复请求变化。
- 服务端以当前会话身份和所有权查询；仅维护者无法读取或创建试用资料。删除与同根写入以账号行、简历根固定锁顺序串行化。删除请求、清理项、正文物理清除和屏障同一短事务提交；故障时共同回滚。
- 删除后本人只能查询不含正文的最小删除状态；旧正文、详情和旧创建操作均不可访问。数据库清理完成不等于旧备份已清除或外部供应商已删除。
- P2-DT-02 的 JD、正式编辑与完整版本选择，P2-DT-03 的真实文件及解析，P2-DT-04 的完整交互和 P2-DT-05 的文件清理恢复、24 小时调度/备份演练仍未完成。未来计划、面试、报告和额度对象的关联删除尚不存在，PF/VP 与完整 ACC 未通过。

开发数据库和现有账号未被本轮测试修改。隔离测试库与忽略目录中的日志为复核而保留；迁移 V3 尚未在开发数据库实际执行，部署或本地首次以新版本启动时需按已有 Flyway 规则检查目标库与迁移历史。
